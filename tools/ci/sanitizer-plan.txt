# The ASan/UBSan partition: where the heavy cases run (docs/development/ci.md, "The sanitizer partition").
#
#   part | process | case name, exactly as `avgen_tests --list-tests` prints it
#   rest | label   | Catch2 filter                  (the rest: that filter minus every case named here)
#   skip | reason  | case name                      (not run under ASan at all; named in every summary)
#
# Read by `tools/ci/catch2_run.py run --plan` (.github/workflows/sanitizers.yml). A job runs one part's
# named processes (`--part`), each an avgen_tests process that runs exactly the cases listed for it,
# and/or some of the rest's Catch2 shards (`--shards`, `--shard-total`, `--shard-first`). So a case
# named here runs in its process and nowhere else, and any other case runs in a rest shard.
# `catch2_run.py plan-check`, which every push runs, counts that against the binary and fails on a
# name that matches no case (a rename) or on a partition that does not add up.
#
# Why a case is placed rather than left to the rest (minutes are Debug + ASan on the hosted runner,
# three processes per 3-vCPU runner, runs 36241405408 and 36321265640, the slowest seen):
#
#   * Cases that share a process-wide fixture run in ONE process, so the fixture is built once. The film
#     in test_abduction_sequence.cpp (`film()`: 90 s of Glowmere Valley 2 at 60 Hz) costs 245-300 min
#     under ASan, and random shards spread its eleven readers over up to eleven processes, each paying
#     it again -- most of the old 18 [stage] shards spent 4-5 h rebuilding the same film.
#   * Every case measured at 29 min or more has a place, so the rest holds nothing over about 26 min
#     and no draw of the shards can stack two long cases together.
#   * Cases that cannot finish in a hosted job at all are skipped, with the measurement that says so.
