# The ASan/UBSan partition: where the heavy cases run (docs/development/ci.md, "The sanitizer partition").
#
#   part | process | case name, exactly as `avgen_tests --list-tests` prints it
#   rest | part    | Catch2 filter                  (that part's rest shards: the filter, minus every case named here)
#   skip | reason  | case name                      (not run under ASan at all; named in every summary)
#
# Read by `tools/ci/catch2_run.py run --plan` (.github/workflows/sanitizers.yml). Each `part` is one job;
# each `process` in it is one avgen_tests process that runs exactly the cases listed for it. A part with
# a `rest` filter also runs that filter, minus every case named anywhere in this file, in Catch2 shards.
# So a case named here runs in its process and nowhere else, and any other case runs in a rest shard.
# The rest filters must cover the default set between them without overlapping: `catch2_run.py
# plan-check`, which every push runs, counts it and fails on a name that matches no case (a rename)
# or on a partition that does not add up.

rest | main  | ~[stage]
# `[.]` because `[stage]` alone also selects the hidden probe "probe: the animal, the beam and the lag"
# ([.][beam][probe][stage]), which the old [stage] parts ran for 94 min although no default run has it.
rest | stage | [stage]~[.]
#
# Why a case is placed rather than left to Catch2's random shards (minutes are Debug + ASan on the
# hosted runner, three processes per 3-vCPU runner, runs 36241405408 and 36321265640):
#
#   * Cases that share a process-wide fixture run in ONE process, so the fixture is built once. The film
#     in test_abduction_sequence.cpp (`film()`: 90 s of Glowmere Valley 2 at 60 Hz) costs 240-300 min
#     under ASan, and random shards spread its eleven readers over up to eleven processes, each paying
#     it again -- most of the old 18 [stage] shards spent 4-5 h rebuilding the same film.
#   * Cases over about an hour get a process of their own, or share one with another, so two of them
#     can never land in the same random shard.
#   * Cases that cannot finish in a hosted job at all are skipped, with the measurement that says so.
