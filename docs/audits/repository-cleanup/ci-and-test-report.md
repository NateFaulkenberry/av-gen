## 2. Changes made

CI and test infrastructure:

- `.github/actions/test-inputs`: a numpy venv (`tools/ci/requirements.txt`, `numpy==2.0.2`, from `/usr/bin/python3`)
  first on `PATH`, and `avgen_world_preview` copied to `build/release/tools/`. Used by both CPU jobs and the three
  sanitizer jobs.
- `ci.yml` build job: packages `avgen_world_preview`, and refuses non-system dylibs.
- `tools/ci/generate-audio.sh`: one run per distinct generator command; each track is checked against its own
  hash. Tested under macOS `/bin/bash` 3.2.
- `cmake/Dependencies.cmake`: fastgltf no longer looks for a system simdjson.
- `.github/workflows/windows.yml`: new, opt-in and dispatch-only (`windows-self-hosted-runner.md`). It runs nothing
  until the owner enables it.

Tests. **No assertion was weakened.** Every SKIP added names the missing input, and fires only when that input is
absent:

- `test_rift`: generates its world (`build.py --scene-only`, under a file lock), or SKIPs with the command. The arc
  cases also need the song.
- `test_engine_seek_parity`: the "with audio" cases SKIP without the song, and now **REQUIRE** the track when the
  song is present. Before, a project that loaded without its audio passed.
- `test_project_system` "Every example in the index exists and loads": now also **requires the scene to load**
  (`requireProjectScene`). A project whose scene failed used to pass on the default orb. Generated entries must
  carry `generate`.
- `test_procedural_engine` and `test_procedural_examples_gpu`: their explicit example lists **REQUIRE** each file.
  They used to skip a missing one silently.
- `test_rebuild_analysis`: drops its duplicate copy of the Rebuild loader.
- New: `tests/unit/test_example_menu.cpp`, readiness, label and tooltip cases (ADR-1340).
- From the code-fix branch: see `code-audit.md` (CA-001 concurrency test, CA-002 path-trace SKIP/FAIL).

## 3. Commands and configurations

Each command is the repository's own: `docs/build.md`, `tools/ci/run-suite.sh`.

```sh
cmake --preset release -DCPM_SOURCE_CACHE=<checkout>/.cache/cpm && cmake --build --preset release
tools/ci/run-suite.sh cpu-assets --out <absolute dir>   # the CPU suite with this machine's assets, 3 shards
tools/gpu-lock.sh build/release/tests/avgen_render_tests # the GPU suite, Apple GPU
python3 tools/review_examples.py --out <dir>             # every example through the menu path (see scene-inventory.md)
python3 tools/check_project_integrity.py                 # project/scene fingerprints and parameter paths
```

`run-suite.sh --out` used to take a relative path as given. The per-shard `TMPDIR` was then relative too, and about ten
tests that compare absolute paths failed (one segfaulted). Found in this sprint; the script now makes the path
absolute.

  flakes on hosted VMs.
