## Root causes found (Phase 5, before any change)

1. **test_rift (5 cases).**
   - `examples/bioluminescent/rift.scene.json` (14 MB) is generated by `build.py` and gitignored. No clean
     checkout has it; neither does the owner's.
   - A fix already exists on the unmerged `proto/astral-furnace-eng` (`2ade3979`): the test generates the
     world with `build.py --scene-only` under a file lock, and SKIPs with the remedy when the tools are absent.
   - CI also needs numpy and `avgen_world_preview` beside the test binary. Otherwise the cases SKIP rather
     than run.
2. **test_engine_seek_parity (2 cases, asset tier).**
   - The project's audio is `~/Desktop/Rebuild.mp3`, a copyrighted song deliberately excluded from CI
     (`tools/ci/test-assets.list`).
   - The cases guard only the farm and alien packs. Without the song, `seekReplaysSignals()` is false and
     the signal clock is never carried.
   - Sibling "with audio" cases pass without exercising audio at all.
3. **sonic-\* scores.** `tools/make_sonic_material.py` needs numpy, which the hosted runner lacks.
   `generate-audio.sh` also runs that one command 7 times concurrently (once per manifest entry).
