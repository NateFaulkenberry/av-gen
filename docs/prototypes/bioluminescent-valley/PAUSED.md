# Biovalley: SHELVED (2026-10-12)

The owner merged the macro showcase and shelved the rest of the Bioluminescent Valley ("Biovalley", examples/biovalley).
This is not Glowmere Valley.

## Shipped (merged to main)

**The macro showcase.** It is a static-camera, audio-reactive forest floor, built from the hero-asset library.
- `python3 examples/biovalley/valley.py` (after a build) writes these into `examples/biovalley/shots/`:
  - `macro.json`: the still;
  - `macro_audio.json`: the same scene with audio routes and phrase tracks, on Trench.
- Every audio response adds on top of a silent baseline, so with no audio it looks the same as the still.
- The owner approved it at P4/P4b. The review media is in `~/Desktop/av-gen-review/45-bioluminescent-valley/macro-showcase/P4b/`.
- The owner sees it as a candidate static-camera LIVE scene, once the water work is done. It is not listed in
  `examples/index.json` yet: a live entry needs `sonic.live`, which this project does not have.

## Open items

- The macro puddle's apparent size depends on the frame. `PUDDLE_LEVEL` in valley.py is the only knob.
- The macro's terrain is the valley's own, cropped (world size 400 x 1900 m around the origin). Live performance has
  not been profiled (owner: no performance work yet).
- The meshes are large. `meshes/`, `shots/` and `sky/` are gitignored and are regenerated by `valley.py`, plus
  `hero_assets/build.py` and `colorways.py` for the library.

## To resume

1. Read `09-macro-showcase.md`, this file, and `08-finishing-log.md`.
2. Rebuild the library if `meshes/hero` or `meshes/env` are missing. Run Blender: see `hero_assets/README` and
   `03-hero-assets.md`.
3. Run `python3 examples/biovalley/valley.py`, then render with
   `avgen --project examples/biovalley/shots/macro_audio.json --render out.mp4 --format video --range 40:65`.
4. For live: add `sonic.live` and an index entry with `"live": true` (test-enforced).
