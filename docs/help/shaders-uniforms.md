# The Shader Contract

Everything below is generated by the engine and is available in the body of `mainImage`.

## Bindings

All in group 0.

| Binding | Declaration | Holds |
|---|---|---|
| 0 | `var<uniform> sys: Std` | the standard uniforms |
| 1 | `var<uniform> inputs: Inputs` | your declared inputs, in order |
| 2 | `var linearSampler: sampler` | clamp to edge, linear, no mips |
| 3 | `var inputImage: texture_2d<f32>` | the scene for a post layer; 1×1 black for a background layer |
| 4 | `var audioSpectrum: texture_2d<f32>` | one row, one texel per FFT bin |
| 5+ | `var <TARGET>: texture_2d<f32>` | one per named pass target, in declared order |

## The `Std` struct

```wgsl
struct Std {
    time: f32,
    timeDelta: f32,
    frameIndex: f32,
    passIndex: f32,
    renderSize: vec2<f32>,
    passSize: vec2<f32>,
    audio: vec4<f32>,
    audio2: vec4<f32>,
    beat: vec4<f32>,
    pad: vec4<f32>,
};
```

| Field | Holds |
|---|---|
| `sys.time` | render time in seconds — the audio position while playing |
| `sys.timeDelta` | seconds since the previous frame |
| `sys.frameIndex` | frames since the start |
| `sys.passIndex` | which pass is drawing, from 0 |
| `sys.renderSize` | the layer's output size in pixels |
| `sys.passSize` | **this pass's** target size, which differs when a pass is scaled |
| `sys.audio` | `(rms, bass, mid, treble)` |
| `sys.audio2` | `(lowMid, highMid, onset, beatPhase)` |
| `sys.beat` | `(bpm, beatCount, barPhase, progress)` |
| `sys.pad` | padding; do not rely on it |

The `onset` lane is the onset strength halved and clamped, so it is 0 to 1 like the others.

Every audio lane reads **0** when there is no analysis frame.

> [!NOTE]
> The uniforms carry a *subset* of the analysis. **Spectral centroid and spectral flux are not
> available to a shader**, and neither are the `music.*` structural events. If you need one of
> those, declare a shader input and route the signal to it as a parameter — which works for any
> signal at all and is the general answer.

## The spectrum texture

`audioSpectrum` is one row, one texel per FFT bin, in 16-bit float:

- `r` — the log-compressed display spectrum, 0 to 1
- `g` — the linear magnitude
- `b`, `a` — 0 and 1

It falls back to a 1×1 black texture when there is no analysis. Sample it with `linearSampler` at
`v = 0.5`.

## Pipeline state

One colour target, no blending, no culling, no depth, no multisampling. **A background layer with
no blend state overwrites the HDR clear**, which is what you want; if you need to composite, read
`inputImage` in a post layer instead.

## Example

```wgsl
/*{ "INPUTS": [ { "NAME": "drive", "TYPE": "float", "DEFAULT": 1.0, "MIN": 0.0, "MAX": 4.0 } ] }*/

fn mainImage(uv: vec2<f32>, fragCoord: vec2<f32>) -> vec4<f32> {
    let bass = sys.audio.y * inputs.drive;
    let bin  = textureSampleLevel(audioSpectrum, linearSampler, vec2<f32>(uv.x, 0.5), 0.0).r;
    let band = step(1.0 - bin, uv.y);
    return vec4<f32>(vec3<f32>(band) * vec3<f32>(0.4 + bass, 0.2, 0.9), 1.0);
}
```

Route `audio.onset` to `shader/<layer name>/drive` and the spectrum flashes on every hit.
