# Troubleshooting

| Symptom | Go to |
|---|---|
| A slider does nothing | [Parameters](help://modulation/parameters) — check for the orange **[A]** |
| The camera will not move with the mouse | [Directing the camera](help://sequencer/camera-direction) — hand it back |
| Something glows but does not light anything | [Emission and bloom](help://rendering/emission-and-bloom) |
| A point light casts no shadow | [Lights](help://rendering/lights) — only directional and spot get maps |
| Shadows flicker, pop or detach | [Shadows](help://rendering/shadows) |
| A scene is slow | [Diagnosing performance](help://performance/diagnosis) |
| A shader shows magenta stripes | [When a shader will not compile](help://shaders/troubleshooting) |
| A project opened with warnings | [Projects and assets](help://troubleshooting/projects-and-assets) |
| Nothing reacts to the music | [Audio and control](help://troubleshooting/audio-and-control) |
| An EXR render has no captions | [Offline rendering](help://rendering/offline-render) |
| The world fills the whole window | [The interface](help://start/interface) |
| Automation appears to do nothing | [Keyframes](help://sequencer/timeline-automation) — check for unbound targets |
